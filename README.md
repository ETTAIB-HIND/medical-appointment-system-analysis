#  Système de Gestion des Rendez-vous Médicaux

##  Description du projet
Ce projet est une application de gestion des rendez-vous médicaux permettant aux patients de prendre des rendez-vous avec des médecins de manière simple et efficace.  
Le système gère les utilisateurs (patients, médecins, administrateurs), les consultations, et les plannings.



##  Objectifs
- Digitaliser la prise de rendez-vous médicaux
- Éviter les conflits d’horaires
- Faciliter la gestion des médecins et patients
- Améliorer l’organisation des consultations


##  Acteurs du système
- Patient
- Médecin
- Administrateur



##  Fonctionnalités principales
- Inscription / Authentification
- Gestion des profils
- Prise de rendez-vous
- Annulation / modification des rendez-vous
- Gestion des disponibilités des médecins
- Notifications
